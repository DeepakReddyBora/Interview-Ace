# Interview Ace 🚀

AI-Powered Interview Preparation Platform built with the MERN Stack.

Interview Ace helps users prepare for technical and HR interviews using AI-generated questions, resume analysis, ATS matching, voice-based interview practice, and intelligent feedback.

---

# 🌟 Features

## 🔐 Authentication

* User Registration & Login
* JWT Authentication
* Protected Routes
* Persistent User Sessions

---

## 🎤 AI Mock Interviews

* AI-generated interview questions
* Technical Interview Practice
* HR & Behavioral Interview Practice
* Voice-based answering
* Text-to-Speech question reading
* AI Answer Evaluation
* Interview Score Generation

---

## 📄 AI Resume Analyzer

* Upload PDF Resume
* ATS Score Analysis
* Strengths & Weaknesses Detection
* Missing Skills Analysis
* Interview Readiness Feedback
* AI Improvement Suggestions

---

## 🎯 Resume Matcher

* Match resume with Job Description
* AI Match Percentage
* Missing Skills Detection
* Strong Skills Identification
* ATS-style Hiring Feedback

---

## 📊 Analytics Dashboard

* Interview Statistics
* Average Score Tracking
* Interactive Charts
* Interview Progress Visualization
* Interview History

---

## 👤 Profile System

* Edit Profile
* Upload Avatar
* Persistent Avatar Storage
* Dark Mode Support

# 🚀 Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/DeepakReddyBora/Interview-Ace.git
```

---

## 2️⃣ Install Frontend Dependencies

```bash
cd frontend
npm install
```

---

## 3️⃣ Install Backend Dependencies

```bash
cd backend
npm install
```

---

# ▶️ Run Locally

## Backend

```bash
cd backend
npm run server
```

---

## Frontend

```bash
cd frontend
npm run dev
```
